# Опыты

Это не инструменты, а разовые исследования: их запускали, чтобы ответить на
один вопрос, и оставили как доказательство ответа. Держать их вместе с рабочими
скриптами — значит через полгода не отличить «этим пользуются» от «это было
проверкой гипотезы».

- **inventory.mjs** — из чего вальт состоит на самом деле. Ответ: содержательный
  слой это 15% файлов и 33% объёма, остальное — хроника и карточки словаря.
  Именно этот прогон показал, что перестраивать надо не структуру, а доступ.

- **constellations.mjs** — созвездия по связям против созвездий по смыслу. Ответ:
  векторные рёбра дают 876 связей, из них 654 между заметками без единой ссылки;
  но на нынешнем корпусе они в основном обнаруживают, что хроника повторяет сама
  себя. Здесь же проверено и опровергнуто, что вычитание среднего направления
  корпуса чинит слипание шаблонных логов.

- **fake-embed.mjs** — заглушка эндпоинта эмбеддингов. Считает векторы
  хешированием слов, смысла в них нет. Годится ровно для проверки тракта:
  сборка → шарды → загрузка → косинус → RRF. Качество на ней мерить нельзя.

Запускать можно, но чинить при поломке необязательно: они своё уже сказали.
