# Осколки — карта памяти

Личная карта второго мозга поверх Obsidian-вальта `s4s4s4s/second-brain`: граф
связей, картотека, поиск, правка заметок и разговор с ИИ по собственным записям.
Статика без сборки — деплой это `git push` в `master`, Pages отдают корень.

Живёт на https://s4s4s4s.github.io/oskolki — без секрета открывается демо-режим
на вымышленном вальте той же структуры.

## Что умеет

**Карта.** Созвездия — папки вальта; крупные (больше 26 заметок) дробятся по
второму уровню, поэтому `brain` распадается на МОЗГ и ЖУРНАЛ. Журналы сессий и
очередь заданий помечены как хроники: они упоминают всё подряд, поэтому
приглушены серым и гасятся одной кнопкой «ТОЛЬКО ЗАМЕТКИ». Раскладки
зоны/силовая/свежесть/зависимости/смысл, кодировка цветом и размером, фильтры,
клавиатура.

**Масштаб карты.** Отталкивание считается по Barnes-Hut, поэтому цена кадра
растёт как n·log n, а не как n². Свёртка созвездий превращает карту в десяток
объектов и выключает физику совсем; окрестность показывает только то, что в двух
шагах от выбранного. Замерено на синтетических 10 000 узлов: кадр 53 мс при
движении, 19 мс в покое, 0.33 мс в свёрнутом виде.

**Поиск — два источника.** «ПАМЯТЬ» ищет по корпусу в браузере: отвечает за
единицы миллисекунд, работает офлайн и ранжирует **тем же кодом**, что воркер
(`js/search.js` — порт `_tools/vault-mcp/worker.js`; расхождение ловит
`node _dev/parity.mjs`). «СЕРВЕР» — настоящий `vault_search`, он видит правки
раньше, чем приложение перечитает индекс. Язык запросов: `tag:`, `type:`,
`zone:`, `status:`, `is:orphan|broken|untagged`, `after:`, `before:`, `-` для
отрицания.

**Смысловой слой (по желанию, выключен).** Векторы кусков лежат в
`_машина/векторы` и складываются с BM25 ранговым способом (RRF). Нужен эндпоинт
эмбеддингов — по умолчанию локальная ollama, ничего не уходит с машины.
Включать только после замера: `node _dev/eval.mjs --vectors <папка>` печатает
попадание@1, попадание@5 и MRR для BM25, векторов и гибрида — и прямо говорит,
стоит ли слой держать. Сейчас BM25 в одиночку даёт MRR 0.539 и 11 из 15
попаданий в пятёрку.

**Похожие и созвездия по смыслу.** У каждой заметки — список похожих: общие
редкие слова плюс мера Адамика–Адара по графу (общий редкий сосед доказывает
родство, общий хаб не значит ничего). Кластеры Лувена дают созвездия по связям,
а не по папкам; одиночки досыпаются по словарю, остальное честно остаётся
россыпью.

**Спросить память.** Экран собирает контекст из найденных фрагментов и
показывает, на чём построен ответ. Без ключа — кладёт готовый пакет в буфер для
любого чата; с ключом Anthropic — отвечает прямо здесь (стриминг). Там же —
адрес вальта как MCP-сервера для подключения других ИИ.

**ИИ-помощники.** Разметить заметку (теги из сложившегося словаря вальта плюс
связи с похожими), описать созвездие, сводка за неделю или месяц. Ключ —
удобство, а не условие: без него тот же запрос уходит в буфер, ответ вставляется
обратно. Ничего не пишется само: предложения приходят галочками.

**Запись.** Быстрая мысль уходит в `daily/ГГГГ-ММ-ДД.md` под раздел «Мысли»
(файл дня создаётся из `templates/Daily.md`). Заметки создаются из шаблонов
вальта, разделы правятся `replace`/`append`/`prepend`, новые разделы дописываются.
Теги, типизированные связи и поля фронтматтера правятся из приложения.
Массовые операции: выделение Ctrl/Shift в картотеке → тег, связь, поле, экспорт.
Конфликт правки показывает дифф «на сервере / ваша правка». Без сети записи
копятся в очереди и уходят сами, когда связь вернётся.

**История.** Список правок заметки из git, дифф любой версии с текущей и возврат
одной кнопкой. Возврат — новая запись поверх текущей, а не переписывание
истории. В вебе нужен воркер с `vault_history`/`vault_at`, в приложении — берётся
из локального git.

**Разбор, лента, люди, здоровье.** Неразмеченное идёт по одной заметке с
готовыми предложениями; лента строит время по дате из имени файла, а не по дате
заливки в git; люди — по последнему упоминанию; здоровье собирает битые ссылки,
сирот, застой и разросшееся.

**Синхронизация.** Корпус лежит в IndexedDB: карта рисуется мгновенно из копии,
свежий индекс подтягивается фоном. Живой канал по WebSocket — пуш с любого
устройства приходит тостом, открытая заметка перечитывается.

## Структура

```
index.html            оболочка: полосы, роутер, регистрация SW
css/app.css           тема «Пульт-обсерватория» (токены в :root)
css/fonts.css         локальные шрифты — внешних запросов нет
js/config.js          адреса, палитра зон, имена созвездий, пороги дробления
js/api.js             настройки, JSON-RPC, инструменты vault_*, живой канал
js/search.js          ПОРТ ранжирования из worker.js + разбор серверной выдачи
js/map.js             трёхслойная карта: BM25 по шардам словаря, ленивый текст
js/corpus.js          карта → модель графа, созвездия, поиск (+ слияние с векторами)
js/query.js           язык запросов: фильтры по тегам, типам, датам, состояниям
js/similar.js         похожие заметки и кластеры Лувена
js/vectors.js         смысловой слой: int8-векторы, косинус, RRF
js/frontmatter.js     разбор и сборка фронтматтера с сохранением порядка ключей
js/store.js           IndexedDB: офлайн-копия корпуса и очередь записей
js/write.js           мысль, заметки, разделы, теги, связи, очередь
js/diff.js            построчный дифф для конфликтов и истории
js/ai.js              контекст-пакет, вызов Messages API, помощники, MCP-конфиг
js/graph.js           canvas-граф: Barnes-Hut, раскладки, свёртка, эго-граф
js/views.js           экраны и модалы
js/main.js            роутер, живой канал, клавиатура
js/demo.js            демо-вальт (структура настоящая, содержимое вымышленное)
desktop/              Electron: своё окно, трей, локальный вальт вместо сети
_dev/server.mjs       стенд: мок воркера поверх локального вальта
_dev/parity.mjs       сверка поиска приложения с worker.js
_dev/eval.mjs         золотой набор: BM25 против гибрида, вердикт по MRR
_dev/fake-embed.mjs   заглушка эмбеддингов — только для проверки тракта
```

## Разработка

```bash
node _dev/server.mjs --vault "C:/Users/sasha/Documents/Obsidian Vault"
```

Открыть http://localhost:8787, URL воркера `http://localhost:8787/mcp`, секрет
`dev`. Запись идёт в `_dev/sandbox/` — настоящий вальт стенд не трогает.
Проверка ветки конфликта: `POST /dev/conflict {"on":true}`; ручной пуш в живой
канал: `POST /dev/push`.

Перед пушем: прогнать все экраны локально, добиться нуля ошибок консоли,
`node _dev/parity.mjs` должен сойтись.

Векторы (когда понадобятся):

```bash
ollama pull nomic-embed-text
node "_tools/vault-mcp/build-vectors.mjs" <вальт> <вальт>/_машина/векторы
node _dev/eval.mjs --vectors <вальт>/_машина/векторы
```

`--dry` у сборщика считает куски и предсказывает объём, ничего не считая.

## Контракт среды

- RPC: `POST {url}` (…/mcp), `Authorization: Bearer <секрет>`, JSON-RPC 2.0;
  `ping` → `{}`; `tools/call` → `result.content[0].text`, `isError` → текст
  ошибки. Неверный секрет или путь → HTTP 404 (намеренно, не 401).
- Живой канал: `POST {url без /mcp}/ticket` → `{ts,t}`; `wss://{хост}/ws?ts&t`;
  события `{type:"push",sha,message,paths,indexTouched}`; билет живёт 2 минуты.
- Корпус: `_машина/карта/карта.json` + `словарь/NNN.json` + `ключи.json`;
  старая схема `_машина/индекс/NN.json` поддерживается как запасная.
- Инструменты записи: `vault_patch`, `vault_append`, `vault_create`,
  `vault_write` (фронтматтер), `vault_history`, `vault_at`.
- Секрет и ключ Anthropic живут только в localStorage устройства и в
  репозиторий не попадают никогда.

## Осталось

- Задеплоить воркер (`npx wrangler deploy` из `_tools/vault-mcp`): без этого в
  вебе нет `vault_write`, `vault_history` и `vault_at` — теги, связи и история
  работают только в десктопном приложении.
- Померить смысловой слой на настоящей модели и решить его судьбу цифрами.
- Прогнать против боевого воркера: форматы ошибок сверены со стендом, но не с
  живым Cloudflare.
