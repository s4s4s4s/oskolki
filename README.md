# Осколки — карта памяти

Личная карта второго мозга поверх Obsidian-вальта `s4s4s4s/second-brain`: граф
связей, картотека, поиск, правка заметок и разговор с ИИ по собственным записям.
Статика без сборки — деплой это `git push` в `master`, Pages отдают корень.

Живёт на https://s4s4s4s.github.io/oskolki — без секрета открывается демо-режим
на вымышленном вальте той же структуры.

## Что умеет

**Карта.** Созвездия — папки вальта; крупные (больше 26 заметок) дробятся по
второму уровню, поэтому `brain` распадается на МОЗГ и ЖУРНАЛ. Журналы сессий и
очередь заданий помечены как хроники: они упоминают всё подряд, поэтому
приглушены серым и гасятся одной кнопкой «ТОЛЬКО ЗАМЕТКИ». Раскладки
кластеры/силовая/свежесть, кодировка цветом и размером, фильтры, клавиатура.

**Поиск — два источника.** «ПАМЯТЬ» ищет по корпусу в браузере: отвечает за
единицы миллисекунд, работает офлайн и ранжирует **тем же кодом**, что воркер
(`js/search.js` — порт `_tools/vault-mcp/worker.js`; расхождение ловит
`node _dev/parity.mjs`). «СЕРВЕР» — настоящий `vault_search`, он видит правки
раньше, чем приложение перечитает индекс.

**Спросить память.** Экран собирает контекст из найденных фрагментов и
показывает, на чём построен ответ. Без ключа — кладёт готовый пакет в буфер для
любого чата; с ключом Anthropic — отвечает прямо здесь (стриминг). Там же —
адрес вальта как MCP-сервера для подключения других ИИ.

**Запись.** Быстрая мысль уходит в `daily/ГГГГ-ММ-ДД.md` под раздел «Мысли»
(файл дня создаётся из `templates/Daily.md`). Заметки создаются из шаблонов
вальта, разделы правятся `replace`/`append`/`prepend`, новые разделы дописываются.
Конфликт правки показывает дифф «на сервере / ваша правка». Без сети записи
копятся в очереди и уходят сами, когда связь вернётся.

**Синхронизация.** Корпус лежит в IndexedDB: карта рисуется мгновенно из копии,
свежий индекс подтягивается фоном. Живой канал по WebSocket — пуш с любого
устройства приходит тостом, открытая заметка перечитывается.

## Структура

```
index.html            оболочка: полосы, роутер, регистрация SW
css/app.css           тема «Пульт-обсерватория» (токены в :root)
css/fonts.css         локальные шрифты — внешних запросов нет
js/config.js          адреса, палитра зон, имена созвездий, пороги дробления
js/api.js             настройки, JSON-RPC, инструменты vault_*, живой канал
js/search.js          ПОРТ ранжирования из worker.js + разбор серверной выдачи
js/corpus.js          индекс → модель графа, созвездия, локальный поиск
js/store.js           IndexedDB: офлайн-копия корпуса и очередь записей
js/write.js           мысль, создание заметок, разделы, досылка очереди
js/diff.js            построчный дифф для конфликтов
js/ai.js              контекст-пакет, вызов Messages API, MCP-конфиг
js/graph.js           canvas-граф: секторы созвездий, LOD, физика
js/views.js           экраны и модалы
js/main.js            роутер, живой канал, клавиатура
js/demo.js            демо-вальт (структура настоящая, содержимое вымышленное)
_dev/server.mjs       стенд: мок воркера поверх локального вальта
_dev/parity.mjs       сверка поиска приложения с worker.js
```

## Разработка

```bash
node _dev/server.mjs --vault "C:/Users/sasha/Documents/Obsidian Vault"
```

Открыть http://localhost:8787, URL воркера `http://localhost:8787/mcp`, секрет
`dev`. Запись идёт в `_dev/sandbox/` — настоящий вальт стенд не трогает.
Проверка ветки конфликта: `POST /dev/conflict {"on":true}`; ручной пуш в живой
канал: `POST /dev/push`.

Перед пушем: прогнать все экраны локально, добиться нуля ошибок консоли,
`node _dev/parity.mjs` должен сойтись.

## Контракт среды

- RPC: `POST {url}` (…/mcp), `Authorization: Bearer <секрет>`, JSON-RPC 2.0;
  `ping` → `{}`; `tools/call` → `result.content[0].text`, `isError` → текст
  ошибки. Неверный секрет или путь → HTTP 404 (намеренно, не 401).
- Живой канал: `POST {url без /mcp}/ticket` → `{ts,t}`; `wss://{хост}/ws?ts&t`;
  события `{type:"push",sha,message,paths,indexTouched}`; билет живёт 2 минуты.
- Корпус: `_машина/индекс/NN.json` — куски `{p,h,t,i}`; `meta.json` —
  `{путь:{u,h,c,b}}`; индекс пересобирает GitHub Action ~30 с после пуша.
- Секрет и ключ Anthropic живут только в localStorage устройства и в
  репозиторий не попадают никогда.
